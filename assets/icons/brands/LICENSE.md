# Brand icons

These SVG files are copied unmodified from [Simple Icons](https://simpleicons.org/)
(npm package `simple-icons`, version 16.28.0 at the time of vendoring), released under
CC0 1.0 Universal. Brand marks remain the property of their owners; see the
Simple Icons legal disclaimer before using one in a way its owner would object to.

`tools/build-icons.mjs` turns this folder into `js/brand-icons.js`. To add an icon,
drop the slug's SVG here and run the tool; do not edit the generated file.
