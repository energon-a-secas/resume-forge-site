    Resume Forge

    A CV builder that treats your resume as data: one YAML document (or JSON, JSON Resume, Markdown, a LinkedIn export) rendered through templates you can switch at any time. Nothing leaves your browser; saves live in this browser's storage.

    • Content: basics, social links with icons, and an ordered list of sections. Every section has a type (experience, skills, icon row, list, text …) and a zone (main or side column). Reorder, move between zones, hide, or delete.
    • Design: template, palette, fonts, banner shape and image, photo shape, heading and entry styles, icon tiles, density, page size.
    • YAML: the same resume as text. Paste a file, apply, export.
    • PDF: the browser's print dialog produces a vector PDF with selectable text and working links. Pick "Save as PDF", set margins to none, keep background graphics on.
    • Keys: T templates · D design · P PDF · S save · Esc close. Inside the YAML panel, Ctrl/Cmd+Enter applies.

    Schema reference: template.yaml · validate a file offline: node validate.mjs resume.yaml · source on GitHub via the footer.
    Runs in your browser: your resume, photos and saves never leave this device.
