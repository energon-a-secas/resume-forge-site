# Resume Forge - Spacing & Layout Guide

## Spacing Presets

### Tight (Recommended for dense content)
- Section: 15px
- Item: 12px
- Paragraph: 8px
- Header: 18px

### Normal (Balanced)
- Section: 20px
- Item: 15px
- Paragraph: 10px
- Header: 25px

### Relaxed (Most readable)
- Section: 30px
- Item: 20px
- Paragraph: 15px
- Header: 35px

## Layout Templates

### Standard (Sidebar + Main)
- Sidebar: 20-40% width (configurable)
- Profile photo in sidebar (top)
- Configurable sidebar sections
- Social icons at bottom of sidebar
- Main content: Name, title, contact, experience

### Big Header (Modern layout)
- Full-width colored header (220px)
- Centered profile photo in header (120px)
- Centered name & title in header
- Contact info & social icons below header
- Two-column content below:
  - Left: Summary + Experience
  - Right: Sidebar sections (Skills, Education, etc.)

## Sidebar Sections (Configurable)

All sections can be:
- Enabled/disabled
- Reordered
- Customized (title, content)

Available sections:
1. **Skills** - Heart-rated skills (1-5)
2. **Education** - School, degree, dates, location
3. **Languages** - Language + proficiency level
4. **Gaming** - PSN/Steam stats (if enabled)
5. **Certifications** - Cert name, issuer, date
6. **Custom** - Free-form text content

## Best Practices

- **Tight spacing** fits 1-2 pages easily
- **Big Header template** for modern, visual resumes
- **Standard template** for traditional resumes
- Disable unused sidebar sections to save space
- Use bullet points (`•`, `-`, `*`) in experience descriptions
- Line breaks (`\n`) are respected in all text fields
