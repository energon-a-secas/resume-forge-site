# CLAUDE.md: Resume Forge

Resume Forge: gaming-inspired resume builder with PSN/Steam stats (resume.neorgon.com)

**Live:** resume.neorgon.com · **Port:** 8822

## Run

```bash
make serve
```

Then open http://localhost:8822. It must be served over HTTP. The app is ES modules, and `file://` blocks them.

## Data

- `localStorage['resume-forge-v1']`
- `worker/`: Cloudflare Worker proxy; secrets are `wrangler secret` bindings, never literals

## Conventions

- Zero build step. Plain ES modules loaded by `js/app.js`.
- Header and footer come from the shared kits. Do not add site-local `.neo-footer` or `.header-bar` CSS.
- The fleet guideline is ~500 lines per module; `js/render.js` is already past it. Split when touching it, do not grow it further.
- `js/app.js` is 51 lines against a 50-line guideline; it should be an entry point, not a module.
